# usecase rules

Rules for use cases. Read before you create or change a use case.

- [UseCases may only depend on Repositories and other UseCases.](usecase/use-cases-depend-only-on-repositories-and-use-cases.md)
- [The domain layer must not know about DTOs or data sources.](usecase/use-cases-do-not-import-dt-os.md)
- [UseCases expose exactly one callAsFunction() and no public state.](usecase/use-cases-expose-single-invoke.md)
- [UseCases must be annotated with @Factory.](usecase/use-cases-use-factory.md)
